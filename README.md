# 🎯 FinTrack - Gestor de Finanças Pessoais

Sistema modular desktop desenvolvido em Java para controle e gerenciamento de transações financeiras.

## 🚀 Tecnologias e Conceitos Utilizados
* **JavaFX (FXML + CSS)**: Interface gráfica limpa, modular e estilizada.
* **JDBC & SQLite**: Persistência de dados robusta e segura.
* **JUnit 5**: Testes de software isolados utilizando banco de dados em memória RAM.
* **Generics & Wildcards**: Arquitetura de repositórios altamente reutilizável.
